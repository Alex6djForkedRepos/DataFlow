# PipeFlow

> **Warning: v3.0 in development -- not yet on NuGet.** For the current stable release (v2.1.0, NuGet: `PipeFlowCore`), see the [v2.1.0-archived tag](https://github.com/Nonanti/PipeFlow/tree/v2.1.0-archived).

A modern, production-grade ETL pipeline library for .NET with DI integration, async-first streaming, and broad data source coverage.
